## Overview

This project implements a web-based viewer for 3D Gaussian Splatting reconstructions. It allows users to explore 3DGS scenes directly in the browser without requiring any installation.

## Features

- Real-time rendering of Gaussian splats
- Support for .ply file format
- Interactive camera controls (orbit, pan, zoom)
- Progressive loading for large scenes
- Mobile-friendly responsive design

## Technical Details

Built with Three.js and custom WebGL shaders optimized for Gaussian splatting rendering.
