A free-form corner of the site — notes, reading lists, experiments, and
whatever else doesn't fit a fixed page. Every page here is a single Markdown
file under `content/space/`. Add a `<name>.md` for a leaf page, or a
`<name>/index.md` folder for a section that can hold its own sub-pages.
